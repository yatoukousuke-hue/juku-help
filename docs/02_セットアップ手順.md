# セットアップ手順（初めての方向け・所要 30〜40 分）

> **2026-09-26 追記：この手順の 1〜3 はすでに完了しています。**
> 公開先は Netlify ではなく GitHub Pages（https://yatoukousuke-hue.github.io/juku-help/ ）です。
> 現在の URL・残作業・更新方法は [04_公開情報（現在の状態）.md](04_公開情報（現在の状態）.md) を見てください。
> 以下は「別の塾用にもう一式作る」「作り直す」ときのための手順です。

この手順で、生徒と講師が使える URL が発行されます。
必要なもの：パソコン、メールアドレス（Supabase と Netlify の登録用）、この `app` フォルダ。

やることは 3 つだけです。

1. **Supabase**（データの保存先）を作って、SQL を 1 回貼り付けて実行する
2. `app/config.js` に Supabase の接続情報を 2 行書く
3. **Netlify** に `app` フォルダをドラッグ＆ドロップして公開する

> 先に動きを見てみたい場合：`app/index.html` をパソコンのブラウザで開くと「お試しモード」で動きます（データはそのブラウザ内だけ）。講師画面は `app/teacher.html`、合言葉は `sensei` です。

---

## 1. Supabase を用意する（15分）

### 1-1. アカウントとプロジェクトを作る
1. https://supabase.com を開き、右上の **Start your project** → **Sign up** で登録します（GitHub かメールアドレス）。
2. ログイン後、**New project** を押します。
   - Organization：そのままでOK（初回は自動で作られます）
   - Name：`juku-help` など好きな名前
   - Database Password：**強いパスワードを生成**（Generate a password）して、**必ずメモ**しておきます（後で使うことはほぼありませんが、無くすと困ります）
   - Region：**Northeast Asia (Tokyo)** を選びます
   - Plan：**Free**
3. **Create new project** を押し、1〜2 分待ちます（画面上の表示が「Setting up project」から変わるまで）。

### 1-2. SQL を実行して表と関数を作る
1. 左のメニューから **SQL Editor**（アイコンは `>_`）を開きます。
2. **New query** を押します。
3. パソコンで `supabase/schema.sql` をメモ帳などで開き、**中身を全部コピー**して、SQL Editor に貼り付けます。
4. 右下の **Run**（または Ctrl+Enter）を押します。
5. 下に「Success. No rows returned」と出れば完了です。
   - エラーが出た場合：貼り付けが途中で切れていないか確認し、もう一度全部貼り付けて Run。この SQL は何度実行しても壊れません。

### 1-3. 接続情報をコピーする
1. 左メニューの **Project Settings**（歯車）→ **API** を開きます。
   - 新しい画面では **Settings → API Keys** / **Data API** に分かれていることがあります。
2. 次の 2 つをコピーします。
   - **Project URL**：`https://xxxxxxxxxxxx.supabase.co` のような文字列
   - **anon public** キー（「Publishable key」「anon」と書かれている、`eyJ...` または `sb_publishable_...` で始まる長い文字列）
   - ※ **service_role** / **secret** と書かれたキーは絶対に使わない・配らないでください。

## 2. config.js に書き込む（3分）

1. `app/config.js` をメモ帳（Windows）や テキストエディット（Mac）で開きます。
2. 上のほうにある 2 行に、コピーした値を貼り付けます。引用符 `"` の内側に貼ります。

```js
  SUPABASE_URL: "https://xxxxxxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...（長い文字列）",
```

3. ついでに、教室名・教科・学年・定型メモも自分の塾に合わせて書き換えます（あとからでもOK）。
4. 保存します。

> **確認**：`app/index.html` をダブルクリックしてブラウザで開き、上に黄色い「お試しモード」の帯が**出なくなっていれば**接続設定は反映されています。

## 3. Netlify で公開する（10分）

### 3-1. 登録
1. https://app.netlify.com/signup を開き、メールアドレス（または GitHub）で登録します。
2. 「What are you building?」のような質問が出たら適当に答えて進みます（Team 名は何でもOK）。

### 3-2. ドラッグ＆ドロップで公開
1. https://app.netlify.com/drop を開きます。
2. パソコンの **`app` フォルダ**（フォルダごと）をブラウザの点線の枠にドラッグ＆ドロップします。
3. 数十秒で `https://（ランダムな名前）.netlify.app` という URL が発行されます。

### 3-3. URL を短く分かりやすい名前に変える
1. 発行されたサイトの画面で **Site configuration**（または Site settings）→ **Change site name** を押します。
2. 覚えやすい名前を入れます。例：`juku-help` → `https://juku-help.netlify.app`
   - すでに使われている名前は登録できません。塾名の略称などを組み合わせてください。
   - これが**生徒に配る URL**です。短縮URLサービス（bit.ly など）は学校のフィルタで止まりやすいので使いません。

### 3-4. 動作確認
- `https://あなたの名前.netlify.app/` → 生徒画面
- `https://あなたの名前.netlify.app/teacher.html` → 講師画面（合言葉 `sensei`）
- `https://あなたの名前.netlify.app/qr.html` → 掲示用 QR ページ

スマホで生徒画面から 1 件送信し、パソコンの講師画面に出てくれば成功です。

## 4. 生徒名簿を入れる（5分）

1. スプレッドシート（Google スプレッドシート / Excel）で、次の 4 列を作ります。`docs/名簿テンプレート.csv` を開いて使っても構いません。

| 生徒番号 | 氏名 | 学年 | 学校名 |
|---|---|---|---|
| 1001 | 佐藤 花子 | 中2 | 第一中 |
| 1002 | 鈴木 太郎 | 中3 | 第二中 |

   - 生徒番号は**塾内で重複しない番号**なら何でもOK（数字でなくても可）。
   - 学年は `config.js` の GRADES と同じ表記（初期値：中1・中2・中3）にします。
2. 4 列分のセルを選択してコピー（見出し行を含めてもOK）。
3. 講師画面 → **設定** タブ → 「名簿の取り込み」の枠に貼り付け → **取り込む**。
4. 名簿は何度でも取り込み直せます（同じ生徒番号は上書き）。退塾した生徒を消したいときは、最新の名簿を貼り付けて「貼り付けた名簿に無い生徒を無効にする」にチェックして取り込みます（記録は残ります）。

## 5. 合言葉を変える（1分）

講師画面 → **設定** → 「合言葉の変更」で新しい合言葉（4文字以上）を入れて変更します。
講師全員に新しい合言葉を伝えてください（古い合言葉で開いている講師は、次回の更新時に再ログインを求められます）。

## 6. 講師に共有する

講師には次の 3 つを伝えます。

1. 講師画面の URL：`https://あなたの名前.netlify.app/teacher.html`
2. 合言葉
3. iPhone なら Safari で開いて **共有ボタン（□↑）→「ホーム画面に追加」**。ホーム画面のアイコンから開くとアプリのように使えます。

初回に「講師名」を入れると、その iPhone に記憶されます（対応カードに担当として表示されます）。

## 7. 教室に掲示する（QR と URL）

1. `https://あなたの名前.netlify.app/qr.html` をパソコンで開きます。
2. 「印刷する」を押して A4 に印刷し、教室に貼ります（QR と URL、使い方 3 行が載っています）。
3. 共有タブレットは、生徒画面を開いて初回の「みんなで使う端末」を選び、ホーム画面に追加しておきます。

## 8. 学校タブレットで開けるか確認する（当日の朝に）

学校支給タブレット 1 台で `https://あなたの名前.netlify.app/` を開き、依頼を 1 件送れるか確認します。

| 症状 | 原因の見当 | 対処 |
|---|---|---|
| ページ自体が開かない（ブロック画面が出る） | `netlify.app` がフィルタ対象 | 下の「別の公開先に変える」を参照。10分で移せます |
| ページは開くが、送信すると「通信できませんでした」 | `supabase.co` がフィルタ対象 | Supabase プロジェクトを別リージョン（Singapore 等）で作り直して URL を差し替えるか、独自ドメインを使う構成に変更（相談してください） |
| 名前の一覧が出ない | 名簿未取込 | 講師画面の設定から名簿を取り込む |

### 別の公開先に変える（netlify.app がブロックされたとき）
画面のファイルは普通の HTML なので、どこに置いても動きます。

- **Cloudflare Pages**（`○○.pages.dev`）：https://dash.cloudflare.com → Workers & Pages → Create → Pages → **Upload assets** → `app` フォルダをアップロード。
- **GitHub Pages**（`○○.github.io`）：GitHub でリポジトリを作り、`app` の中身をアップロード → Settings → Pages → Branch: main を選ぶ。

どちらも Supabase 側の設定は変更不要です。

## 9. 更新のしかた（設定を変えたとき）

`config.js` などを書き換えたら、Netlify のサイト画面の **Deploys** タブを開き、`app` フォルダをもう一度ドラッグ＆ドロップします。URL は変わりません。
Service Worker はキャッシュをしない設定なので、生徒・講師側はページを開き直すだけで新しい内容になります。

## 10. 知っておくこと

- **Supabase の無料プランは、1週間まったく通信が無いとプロジェクトが一時停止**します。長期休み明けに「通信できませんでした」と出たら、Supabase の管理画面でプロジェクトを開き **Restore project** を押してください（数分で復帰）。
- データは Supabase の **Table Editor** で表としてそのまま見られます（`requests` = 依頼、`students` = 名簿）。
- バックアップ：講師画面の記録タブから期間を指定して CSV を書き出しておけば十分です。
- 講師画面のパスワードは「合言葉」だけなので、URL と合言葉は生徒に知られないようにしてください。生徒画面には他の生徒の依頼は表示されず、データベースにも直接アクセスできない作りになっています。
