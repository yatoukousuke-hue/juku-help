## Supabase について

- 組織：yatoukousuke-hue's Org（Pro プラン）に `juku-help` プロジェクトを作成。リージョン東京。
- 稼働コンピュート MICRO のため **月 $10 の追加課金**が発生します（作成時に同意済み）。一時停止はしません。
- データベースのパスワードは Supabase が自動生成したものです。必要になったら Project Settings → Database → Reset database password で再設定できます。
- 表の中身は Supabase の **Table Editor** で見られます（`requests` = 依頼、`students` = 名簿、`app_settings` = 合言葉）。
- 動作確認で送った依頼（「動作テスト（消してOK）」など、状態 = 取消）が残っています。消したい場合は Table Editor の `requests` から削除してください。

## 更新のしかた

画面のファイルは GitHub の `main` ブランチに push すると **1〜2 分で自動公開**されます。

### 方法A：GitHub のサイト上で編集（パソコンのブラウザだけで完結）
1. https://github.com/yatoukousuke-hue/juku-help/blob/main/app/config.js を開く
2. 右上の鉛筆アイコン（Edit）を押す
3. 書き換えて、右上の **Commit changes...** → **Commit changes**
4. 1〜2 分後に公開 URL に反映（反映状況は https://github.com/yatoukousuke-hue/juku-help/actions で確認）

### 方法B：このフォルダで編集して push
```bash
git add -A
git commit -m "設定変更"
git push
```

### 方法C：Claude に頼む
「教室名を〇〇に変えて公開して」のように伝えれば、編集から push まで行えます。

### Vercel 側の更新
Vercel は GitHub リポジトリ（yatoukousuke-hue/juku-help、Root Directory = `app`）に接続済みなので、**GitHub Pages と同じく push だけで自動更新**されます。
反映状況：https://vercel.com/yatoukousuke-hues-projects/eimeimizutani-support

手動で今すぐ更新したいときは PowerShell で `.\dev\deploy_vercel.ps1`（この PC は PC 名が日本語のため、そのまま `vercel` を打つと落ちます。スクリプトが回避します）。

### データベース定義（schema.sql）を変えたとき
Supabase の SQL Editor で `schema.sql` を貼り付けて Run（何度実行しても安全）。「Potential issue detected」と出たら「Run query」でOK（古い関数の入れ替えのため。データは消えません）。
