📄 プリントがほしい ／ ✋ 質問したい

スマホ・タブレットから送ると、先生が順番に対応します
QRが読めないときはこのURLを入力
eimeimizutani-support.vercel.app
ホーム画面に追加すると次からワンタップ
iPhone：共有ボタン（□↑）→「ホーム画面に追加」
Android：メニュー（⋮）→「ホーム画面に追加」

使い方

  1. QRを読む → 初回だけ「自分の端末」か「みんなで使う端末」を選ぶ
  2. 「プリントがほしい」か「質問したい」を押す
  3. 学年 → 自分の名前 → 教室 → 教科 を選ぶ（席番号はいりません）
  4. プリント：目的を選ぶ → 確認に答える → 単元名・難易度・量 → 送信
    質問：「シンキングした？」→ 単元名・ページ → 「早めに来てほしい」か「あとででOK」→ 送信
  5. 受付番号が出たら、席で待つ。「先生が向かっています」と出たらもうすぐです
プリントを頼む前に
✅ ワークはやった？　✅ テスト形式はやった？　✅ 範囲表は確認した？
まだなら、先にそっちをやろう。「苦手だからポイント確認から」は確認なしでOK。
質問する前に
✅ シンキングした？（自分で5分考えて、ノートに途中まで書いた？）
それでも分からなければ質問OK！
取り消したいとき：自分の依頼の「取り消す」を2回押す（先生が対応を始める前だけ）。
みんなで使う端末：送信後に出た受付番号をおぼえておくと、あとで「受付番号で確認」できます。
同じ端末から15秒以内の連続送信はできません。他の人の依頼は表示されません。

合言葉： 
（生徒に見えないところに書いてください）

最初にやること（1回だけ）

  1. QRを読んで開く → 合言葉と自分の名前を入れて「入る」
  2. ホーム画面に追加（iPhone：共有ボタン → ホーム画面に追加）。以後はアイコンから開く
  3. 右上の 🔔 が鳴る状態か確認（マナーモードだと鳴りません）。画面を開いている間はスリープしません

授業中の流れ

  1. 上の3つの数字：待ち件数／早めに来てほしい／最長の待ち時間。「早めに」をタップするとそれだけに絞れます
  2. カードの「対応する」を押して席へ（生徒の画面に「○○先生が向かっています」と出ます）
  3. 終わったら「完了にする」→ 定型ボタン（理解できた／要フォロー／類題を渡した…）＋一言 → 完了
  4. 名前が「名簿外」の依頼は「名簿に紐づけ」で本人に結びつけると、記録に残ります

カードの見方

赤枠・点滅「早めに来てほしい」の質問。5分を超えると点滅し、1分ごとに音が鳴ります
2行目種類・教科・目的・単元・ページ・難易度・量・補足
「テスト形式未」など赤い印プリントを頼む前の確認が「まだ」だった項目。理由も表示されるので、先にワーク等をやらせるかの判断材料に
右上「更新 12:34」最終更新時刻。赤い「通信できません」が出たら電波を確認

記録・保護者報告

「記録」タブ → 生徒と期間（今月／先月ボタン）→ 表示。質問回数・教科別・プリント回数・要フォロー件数が出ます。「保護者報告のもとを作る」→ コピーして LINE 等に貼り付けて手直し。CSV も出せます。
日付が変わると完了分は一覧から消え「記録」に残ります。前日の「待ち」が残っていたら完了か取消にしてください。
