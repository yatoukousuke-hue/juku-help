# 運用ガイド（毎日の使い方）

## 生徒の使い方（掲示・口頭で伝える内容）

1. QR を読む（または掲示の URL を打つ）
2. 初回だけ「自分の端末」か「みんなで使う端末」を選ぶ
   - 自分のスマホ → **自分の端末**（名前・教室・席が記憶される）
   - 校舎のタブレット → **みんなで使う端末**（送信後に入力が消える）
   - 学校支給タブレットは本人専用なら「自分の端末」でOK
3. 「プリントがほしい」or「質問したい」→ 学年 → 名前 → 教室 → 席 → 教科 → 内容 → 送信
4. **受付番号**が出る。共有端末の人は番号をおぼえておく（あとで「受付番号で確認」に入れると状態が見える）
5. 取り消したいときは、自分の依頼の「取り消す」（講師が対応を始める前だけ）

ホーム画面に追加すると次回からワンタップで開けます：
- iPhone：Safari の共有ボタン → 「ホーム画面に追加」
- Android：Chrome のメニュー（⋮）→ 「ホーム画面に追加」／「アプリをインストール」
- iPad / Chromebook も同様

## 講師の使い方

### 一覧画面
- 上の 3 枚のタイル：待ち件数／「すぐ来てほしい」件数／いちばん長く待っている時間
- タブ：**待ち**（古い順）／**対応中**／**完了**（今日の分。取消も含む）
- 絞り込み：教室・種類
- 5 秒ごとに自動更新。新しい依頼が来ると **音＋バッジ（タブの数字）＋カードが黄色く光る**
  - 音が鳴らないときは右上の 🔔 が 🔕 になっていないか確認。iPhone はマナーモードだと鳴りません（バイブは Android のみ）
  - iPhone の画面を消していると更新されません。バックグラウンド通知（プッシュ通知）は現在の版では対応していません
- 「すぐ来てほしい」の質問は赤枠。5 分（config.js の URGENT_ALERT_MIN）を超えると点滅します

### カードの操作
- **対応する**：担当講師名つきで「対応中」へ
- **完了**／**完了にする**：メモ画面が開く → 定型ボタン（複数可）＋自由記入 → 完了
  - 待ち状態から直接「完了」も可能（プリントを渡しただけの場合など）
- **取消**：生徒が帰った・重複などのとき
- **待ちに戻す**：間違えて対応中／完了にしたとき
- **名簿に紐づけ**：生徒が「その他（手入力）」で送ってきた依頼を、名簿の生徒に結びつけます（記録が生徒別に集計されるようになります）。「名簿外」と表示されているカードが対象です

### 日付が変わったら
完了・取消の依頼は翌日の一覧から消え、「記録」タブで見られます。待ち・対応中のまま残った依頼は翌日も一覧に残るので、前日の分は「取消」か「完了」にしてください。

### 記録タブ（生徒別・保護者報告）
1. 生徒と期間を選んで **表示**
2. 集計（質問回数・教科別内訳・プリント回数・要フォロー件数）と一覧が出ます
3. **保護者報告のもとを作る** → 文章が出るので **コピー** → LINE やメールに貼り付けて手直し
   - 文章は講師メモと集計だけから作られます（記録にないことは書きません）
4. **CSV**：期間内の全生徒の依頼を書き出します。Excel / Google スプレッドシートで開けます（文字化けしないよう BOM 付き UTF-8）

### 設定タブ
- 名簿の取り込み（詳細はセットアップ手順の 4）
- 合言葉の変更
- 掲示用 QR ページへのリンク／ログアウト

## 設定を変えたいとき（config.js）

| 変えたいこと | 場所 |
|---|---|
| 教室名 | `CLASSROOMS` |
| 教科 | `SUBJECTS` |
| 学年 | `GRADES`（名簿の学年表記と揃える） |
| 完了メモの定型文 | `MEMO_TEMPLATES`。「要フォロー」として数える語は `FOLLOW_TAG` |
| 自動更新の間隔 | `REFRESH_SEC_TEACHER`（講師）／`REFRESH_SEC_STUDENT`（生徒） |
| 「すぐ来てほしい」の強調までの分数 | `URGENT_ALERT_MIN` |
| 席番号を必須にする | `SEAT_REQUIRED: true` |
| 席番号を文字で入力させる（例: A-3） | `SEAT_INPUT: "text"` |
| 塾名をトップに表示 | `JUKU_NAME` |

変更後は `app` フォルダを Netlify にもう一度ドラッグ＆ドロップします。
合言葉だけは config.js ではなく講師画面の設定から変更します。

## いたずら・トラブル対応

- 同じ端末から 15 秒以内の連続送信、1 時間に 30 件超は自動で拒否されます。
- 明らかないたずら依頼は講師画面で「取消」に。記録には残ります（取消は集計から除外）。
- 依頼は削除されません。Supabase の Table Editor（`requests` 表）から手動で消すことはできますが、通常は不要です。

## ファイル構成

```
app/            公開するフォルダ（これを Netlify にドロップ）
  index.html      生徒画面
  teacher.html    講師画面
  qr.html         掲示用 QR
  config.js       設定（ここだけ編集）
  common.js       共通処理（接続・お試しモード）
  style.css       見た目
  lib/            同梱ライブラリ（Supabase / QR）
  icons/          アプリアイコン
  manifest*.webmanifest, sw.js   ホーム画面追加用
supabase/schema.sql   データベース定義（Supabase の SQL Editor で実行）
docs/           この文書類
dev/            開発用（動作テスト。運用には不要）
```

## 2026-09-26 更新：生徒の入力の流れ（現在の版）

### プリントがほしい
1. だれ？（学年 → 名前を選ぶ。名前で検索もできる。名簿にない場合は手入力）
2. どこ？（3階大教室／個別部屋／2階中教室）
3. 教科
4. **プリントの目的**（上ほど優先度が高い）
   - 苦手だからポイント確認から … 事前チェックなしで頼める
   - 類題演習用／弱点補強用／テスト形式 … 次の **事前チェック** に答える
5. 事前チェック：「ワークはやった？」「テスト形式はやった？」「範囲表は確認した？」を「やった／まだ」で回答
   - 「まだ」があると「まず○○を先にやろう」と表示。それでも必要なときは **理由を書けば送れる**（講師画面に「○○未」と理由が表示されるので、講師が判断できます）
6. 単元名（必須）・範囲のページ（任意）・難易度（基礎／標準／応用）・量（少なめ／ふつう／多め）・補足（任意）
7. 送信 → 受付番号

### 質問したい
1. **シンキングした？**（した／まだ）… 「まだ」を選ぶと「まず5分考えてみよう」と表示され、質問には進めません
2. だれ？ → どこ？ → 教科
3. 単元名・ページや問題番号・一言（任意）
4. 急ぎ度：**早めに来てほしい**／あとででOK
5. 送信 → 受付番号

席番号・生徒番号は使いません。

### 講師画面の追加機能
- カード2行目に「目的・単元・ページ・難易度・量」。事前チェックが「まだ」の項目は **赤い「○○未」** と理由が出ます
- サマリーの「🔴 早めに」タイルをタップすると、早めに来てほしい質問だけに絞り込み
- 「早めに来てほしい」が5分以上放置されると1分ごとに再アラート音
- 画面を開いている間はスリープしない（対応端末のみ）。右上の「更新 12:34」で通信状態が分かり、通信できないときは赤く表示
- 設定タブ →「通知を許可する」で、画面を閉じているときの通知（Android／PC。iPhone はホーム画面に追加したアイコンから開いた場合のみ）
- 記録タブに「今月／先月／直近3か月」ボタン
- 名簿の取り込みは **学年を選んで「氏名・学校名」の2列を貼り付け** に変更（生徒番号は不要）
- 取消・合言葉変更などの確認は、ダイアログではなく「もう一度押す」方式

### 設定で変えられる項目（追加分）
| 変えたいこと | config.js の場所 |
|---|---|
| プリントの目的の一覧・どれに事前チェックを求めるか | `PRINT_PURPOSES`（`needsCheck`） |
| 事前チェックの質問 | `PRINT_CHECKS` |
| 量・難易度の段階 | `PRINT_AMOUNTS` / `PRINT_DIFFICULTIES` |
| 急ぎ度の言い方 | `URGENCY_LABELS` |
| シンキング確認の文言 | `THINKING_CHECK` |
| 共有端末の放置リセットまでの秒数 | `SHARED_IDLE_SEC` |

## 2026-09-27 更新：教科書ページの必須化とプリント指示書

- 生徒は **教科書のページ（英語は「教科書のユニット」）を必ず入力**します（プリント・質問とも）。教科ごとの言い方・必須かどうかは `config.js` の `RANGE_FIELDS` で変更できます（例：国語を「教科書の作品名」にする、など）。
- 講師画面のプリント依頼カードに **「📄 指示書」** ボタンが付きました。依頼内容（学年・名前・学校・教科・目的・単元・範囲・難易度・量・事前チェックの結果・理由・本人の補足）をテンプレートに当てはめた文面が出ます。
  - **コピー** → AI や教材システムに貼り付けてプリントを作る元にする
  - **印刷** → 指示書だけが印刷されるので、作ったプリントに添えて渡せる
  - 文面のテンプレートは `config.js` の `PRINT_SLIP_TEMPLATE`。`{unit}` `{range}` `{difficulty}` などが自動で置き換わります。文面の見本があれば、その形に合わせて書き換えられます

## 2026-09-27 更新②：同じ依頼のまとめ・経過時間

- 絞り込みに **学年** と **教科** を追加。並び順を「古い順」と「**学年→教科→単元**」で切り替えられます。
- 同じ学年・教科・単元のプリント依頼が2件以上あると、一覧の上に「🔁 中2 数学「一次関数」2人」のようなまとまりが出ます。タップするとその依頼だけに絞られます。カードにも「🔁 同じ単元 あと○人」が出ます。
- 絞り込んだ状態で「📄 表示中のプリント○件をまとめて指示書」を押すと、対象の生徒一覧＋各人の指示書が1つの文面になります（1枚のプリントで済ませたいときに）。
- 対応中のカードも **「受付から○分（対応○分）」** と表示します。受付から10分を超えると、待ち・対応中とも時間が赤くなります。
- 「取消」を1回押した状態（本当に取消）は、5秒ごとの自動更新をまたいでも4秒間保持されます。

## 2026-09-27 更新③：中学校

- 生徒は「だれ？」の次に **中学校**（水谷・本郷・富士見東・志木・宗岡・その他）を選びます。名簿に学校が入っている生徒は自動で選ばれます（変更可）。「その他」は学校名を自由入力できます（空でも可）。
- 講師画面：カードの名前の横に「中2・水谷」のように表示。絞り込みに **学校** を追加。「同じ依頼」のまとまりも **学校込み**で判定します（同じ学年でも学校が違えば別のまとまり）。指示書・まとめ・CSV にも学校が入ります。
- 学校の一覧は `config.js` の `SCHOOLS` で変更できます。

## 2026-09-28 更新：おすすめテキスト・点数・前回のプリント（講師画面）

プリント依頼のカードに「パッと見」の欄が付きました（生徒画面には出ません）。
- **📈 点数とレベル**：その教科の直近の定期テストの点数（前回の点数も）、目標点、そこから判定した **おすすめレベル（基礎／標準／応用）**。依頼の難易度と合わないときは ⚠ で注意（例：「目標が高いので基礎だけでは物足りないかも」「苦手なので応用は早いかも」）。
  - 判定の基準は `config.js`：`SCORE_BANDS`（〜49 基礎、50〜74 標準、75〜 応用）、`TARGET_HIGH`（85 以上なら標準以上）、`TARGET_LOW`（60 未満なら基礎から）。
- **📚 テキスト候補**：教科 × レベル × 目的で `app/materials.js` から選んだ上位3つ。「詳細」を開くとそのレベルの候補全部と伊藤先生のコメントが見えます。
  - **手動で更新したいとき**は `app/materials.js` を編集（name／level／uses／note）。push で反映。
- **📄 前回のプリント**：その生徒の直近のプリント（日付・教科・単元・目的・済／待ち）、今日の枚数、7日間の枚数。前回が今日か3日以内に完了していれば **「さっきのプリントやった？」** と促します。
- **目標点**：「詳細」→「目標を設定」で教科ごと・5科の目標を入れられます（次のテストの目標）。
- **点数の取り込み**：校舎統合のテスト結果シートから 2024〜2026 年度の点数を取り込み済み（名簿の 94 人分）。新しいテストは 講師画面 → 設定 → 「定期テストの点数の取り込み」に テスト名（例 2026.3）と「氏名・英・数・国・理・社」の列を貼り付けて取り込みます。
- 指示書の文面にも「直近の点数／目標／おすすめレベル／テキスト候補」が入ります。
- 記録タブの生徒別画面に点数の一覧表が出ます。
